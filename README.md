# fastcampus-project-board
[오프라인] 김은호의 백엔드 실무 로드맵 : Spring Boot 포트폴리오 5주 완성 강의에 참여한 레포지토리 입니다.  
강의를 들으며 작업한 내용, **자발적으로 작업해서 리뷰받은** 내용들이 같이 있습니다.  

## 개발 환경  
- Intellij IDEA
- Java 17
- Spring Boot 2.7.0

## 기술 세부 스택
Spring Boot
- Spring Web
- Spring Data JPA
- H2 Database
- MySQL Driver
- Lombok

그 외
- QueryDSL 5.0.0
